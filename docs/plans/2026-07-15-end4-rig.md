# end-4 Third Rig — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить end-4/dots-hyprland (illogical-impulse) третьим ригом в
dual-rig систему `~/dotfiles`, не ломая caelestia/ilyamiro; бинды по контракту
`KEYBINDS.md`, полная интеграция цветов, работающий хот-свитч.

**Architecture:** end4 на lua (как caelestia), оверрайды в `custom/*.lua`
(переживают апдейты, тот же `hl.bind` API). Наши бинды — независимый порт
(подход B) в его `custom/keybinds.lua`; риг-зависимые действия через 3-ю ветку
`bin/rigdo`. Цвета — 3-я ветка `apply_rig_colors` + matugen как контестируемый
каталог. Профиль — `profiles/end4/` по шаблону ilyamiro.

**Tech Stack:** Hyprland (lua/hyprkcs provider), Quickshell (`qs -c ii`),
matugen + kde-material-you-colors, fish/bash-скрипты dotfiles, SDDM.

## Global Constraints

- Спека: `docs/specs/2026-07-15-end4-rig-design.md`. Источник правды биндов —
  `KEYBINDS.md` (корень).
- **Не трогать caelestia-риг** (подход B). Изменения только в `profiles/end4/`,
  `bin/rigdo`, `apply_rig_colors`, matugen-каталогизации, bootstrap/доки.
- **Домен без юнит-тестов**: верификация = наблюдаемое поведение (relogin, жать
  бинд, `hyprctl binds`, `pgrep`, `journalctl`). Каждая задача заканчивается
  конкретной проверкой.
- **Интерактивные шаги** (Фаза A): sudo и installer end4 — ЧЕРЕЗ пользователя
  (`!`-префикс). Агент не гонит sudo сам.
- Коммитить после каждой задачи. Все правки — на ветке `end4-rig`, НЕ в основной.
- Мина: quickshell-версия ii vs `quickshell-git` (шелл ilyamiro). Проверить в
  Задаче 1 ДО установки.
